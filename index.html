Airfoil flow with PINNs

A study of two-dimensional flow around an airfoil, first with potential-flow methods and then with physics-informed neural networks that learn the flow while respecting its equations. The repository has the Python notebooks, trained models, MATLAB scripts, datasets and flow-field results.

The model here is the potential-flow baseline: a Joukowski airfoil with the Kutta condition.

Field
Computational methods
Tools
Python, PyTorch, PINN, potential flow
Code
airfoil-flow-pinn

Reciprocating pump dynamics

A Simscape Multibody model of a reciprocating pump. I compared running at 100 and 300 rpm and looked at what adding a flywheel does to the torque and to how steadily the crank turns.

Without a flywheel the crank slows on every delivery stroke. Add one and the speed trace flattens.

Field
Multibody dynamics
Tools
MATLAB, Simscape Multibody
Code
reciprocating-pump-dynamics

DC motor speed control

Modelling and simulation of a separately excited DC motor from its physics, then comparing open-loop behaviour with closed-loop speed regulation: a PI controller with armature-voltage saturation, in MATLAB and Simulink.

Push Ki up to see overshoot, and switch the voltage limit to see why saturation matters.

Field
Control and simulation
Tools
MATLAB, Simulink
Code
dc-motor-speed-control

Forklift crane attachment

A removable, manually adjustable crane attachment for a 3-ton forklift. The work covers stability checks, static loading, bolts, pins, welds, structural members, manufacturing drawings and a complete SolidWorks assembly.

The model checks tipping about the front axle. It's an academic design and hasn't been built or certified for lifting.

Field
Mechanical design
Tools
SolidWorks, machine design, structural analysis
Code
forklift-crane-attachment

Two-stage gearbox

Design and analysis of a two-stage reduction gearbox: gears, shafts, bearings and housing, component selection, the calculations behind them and the final SolidWorks assembly.

Drag the input gear. Each stage trades speed for torque.

Field
Machine design
Tools

ANSYS Fluent flow analysis

A set of CFD studies: flow in a diffuser, pressure loss in pipe elbows and compressible flow through a nozzle, with MATLAB scripts for extra processing and plots of the results.

The model is the textbook isentropic solution for the nozzle case, the one the CFD gets checked against.

Field
CFD
Tools
